# 🕹️ Tic Tac Toe with AI (React)

A modern, interactive Tic Tac Toe game built using **React.js** — play solo or challenge an unbeatable AI opponent!

---

## 🧠 Overview

This project is a feature-rich implementation of the classic Tic Tac Toe game, developed to practice and demonstrate key concepts in modern front-end development with React. It supports human vs. human, human vs. AI (with multiple difficulty levels), and maintains scores across rounds.

---

## 🚀 Features

- ✅ Classic 3x3 Tic Tac Toe grid
- ✅ Player vs Player mode
- ✅ Player vs AI mode with 3 difficulty levels:
    - 🟢 Easy (random)
    - 🟡 Medium (block or win)
    - 🔴 Hard (Minimax)
- ✅ Choose who goes first (Player or AI)
- ✅ Score tracking between rounds
- ✅ Reset score button
- ✅ Win animations with:
    - 🎉 Confetti
    - 🟥 Red line highlighting the winning direction
- ✅ Modal popup on win/tie
- ✅ Leaderboard-st
